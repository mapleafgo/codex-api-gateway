# 工具调用契约设计

## 问题

Chat 上游模型调用了当前会话已声明的工具，但没有遵守工具 schema 和前置
条件，自行编造工具身份、参数字段或契约要求预先取得的值。这不是某一种
工具的专属问题，任何工具都可能发生同类错误。

## 方案

在中英文基线指令的通用工具约束中新增统一规则：

- 工具调用必须遵守当前工具声明的准确名称、schema 和前置条件。
- 禁止编造未声明的工具、参数字段或前置结果。
- 当工具契约要求使用其他工具返回的值时，必须使用当前会话中实际返回的
  精确值；没有可用结果时禁止调用该工具。

中英文规则必须保持语义、强度与边界一致。

## 边界

不针对 Skill、MCP 或任何具体工具增加特例。不修改 Chat 转换、工具 schema、
工具执行、路由或会话状态。网关继续遵守“形状透传，结果归上游”，不校验
通用 function arguments。

## 验证

- 检查中英文新增规则逐项对应。
- 检查规则位于通用工具约束，不落入具体 Skill 或工具章节。
- 运行 `task check`，确认基线文档改动不影响现有门禁。
