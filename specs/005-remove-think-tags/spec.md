# Feature Specification: 剔除正文思维标签处理

**Feature Branch**: `005-remove-think-tags`

**Created**: 2026-08-20

**Status**: Draft

**Input**: User description: "我们剔除这个标签的处理吧，这种旧东西，不用管了"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 正文原样透传（不再识别思维标签）(Priority: P1)

Chat 上游可能把思维过程以内嵌标签的形式写在正文里。本需求下，网关不再把这种标签
当特殊语法处理，标签连同其包裹内容一律作为普通正文原样返回，不剥离、不改写、不
产生推理内容。

**Why this priority**: 这是剔除动作的核心目标，直接决定用户可见正文的透传语义。

**Independent Test**: 向转换层输入含完整标签、残缺标签、跨分片标签的 Chat 流，
验证输出正文与上游输入逐字一致，且没有任何推理内容产生。

**Acceptance Scenarios**:

1. **Given** 上游流式正文包含完整开闭标签及其间文本，**When** 网关完成转换，
   **Then** 标签与文本按原样进入用户可见正文，不产生推理内容。
2. **Given** 标签被拆成多个流式分片，**When** 网关拼接处理，**Then** 各分片按
   普通正文原样透传，不做跨分片拼接或语义识别。
3. **Given** 流结束前仍有半个标签残留在正文尾部，**When** 网关收口，**Then**
   残留文本作为普通正文收口，不触发任何标签状态逻辑。

### User Story 2 - 独立推理字段映射保持不变 (Priority: P2)

上游通过独立字段（如 `reasoning_content`）返回推理内容时，网关仍按既有协议映射
转入客户端推理通道。剔除动作只针对正文标签，不得影响独立推理字段的既有行为。

**Why this priority**: 防止剔除误伤协议字段映射，是本次变更的回归保护面。

**Independent Test**: 对含独立推理字段的 Chat 流重复既有验收路径，推理内容仍按
既有方式映射，正文部分原样透传。

**Acceptance Scenarios**:

1. **Given** 上游分片携带独立推理字段，**When** 网关处理，**Then** 推理内容仍
   按既有映射进入客户端推理通道。
2. **Given** 同一分片同时携带独立推理字段与正文标签，**When** 网关处理，**Then**
   推理字段正常映射，正文标签原样透传，二者互不干扰。

### Edge Cases

- 标签跨多个流式分片出现时：不拼接、不暂存，按普通文本逐片透传。
- 流结束处于标签文本中间时：残留内容按普通正文收口，不产生中间状态。
- 同一分片既有独立推理字段又有正文标签时：推理字段走既有映射，正文原样透传。
- 并发请求处理时：剔除后不得依赖任何跨请求共享状态，行为结果一致。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST NOT 识别、剥离或改写正文中的思维标签，标签及其包裹内容
  MUST 以普通正文形式原样透传给客户端。
- **FR-002**: 系统 MUST NOT 因正文标签产生推理内容。
- **FR-003**: 系统 MUST 保持上游独立推理字段到客户端推理通道的既有映射不变。
- **FR-004**: 系统 MUST 在流结束时按普通文本收口残留的标签文本，MUST NOT 留下
  跨请求残留状态。
- **FR-005**: 系统 MUST 保证剔除后并发请求行为一致，MUST NOT 依赖任何跨请求
  共享状态完成正文透传。

### Key Entities

- **正文内容**: 用户可见文本；剔除后由上游到客户端原样透传。
- **推理内容**: 客户端推理通道内容；且仅来源于上游独立推理字段，不再来源于正文标签。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 覆盖完整标签、残缺标签、跨分片标签的流式正文，输出正文与上游输入
  逐字一致，因标签产生的推理内容为 0。
- **SC-002**: 基于独立推理字段的既有推理映射验收全部保持通过，行为无回归。
- **SC-003**: 上述场景重复运行 3 次结果一致，并发运行无状态残留。
- **SC-004**: 全量门禁（格式、静态检查、全部测试、race）通过。

## Assumptions

- 剔除范围仅限 c 路径的正文思维标签解析；`a` / `r` 路径本来不涉及该解析，不在
  本需求影响面内。
- 上游独立推理字段（如 `reasoning_content`）映射属于协议字段映射，保留不删。
- 历史规格（前后两版思维标签系列）与相关设计文档按"旧东西不用管"处理，保留为
  历史记录，不在本需求交付范围内继续维护。
- 本轮不引入任何替代标签能力（如通用标签注册表）。
